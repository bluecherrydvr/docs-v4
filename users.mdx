---
title: Manage users
description: Add, edit, and remove DVR user accounts and control admin access.
---

You manage accounts on the **User Management** page.

Only administrators can open this page. You need the admin flag on your own account first.

## View the user list

The table shows each account's **Username**, **Name**, **Email**, and **Role**.

A **Role** of **Admin** means the account can change system setup and configuration. A **Role** of **User** means a regular account.

## Add a user

1. Click **Add User**.
2. Fill in **Username**, **Email**, and **Full Name**.
3. Enter a **Password**. New users require one.
4. Select **Administrator Access** only if this person should configure the system.
5. Click **Create User**.

Usernames need at least 3 characters. Passwords need at least 8 characters.

## Edit a user

1. Click the edit icon next to the account.
2. Update the details in the **Edit User** dialog.
3. Leave **Password** blank to keep the existing password.
4. Click **Update User**.

Only an administrator can change the **Administrator Access** flag.

## Delete a user

1. Click the delete icon next to the account.
2. Confirm the deletion.

You cannot delete your own account. Deleted accounts lose access immediately.

## Camera access per user

Camera and PTZ permissions are stored as per-user device lists. These lists use device IDs.

There is no permission editor in the web UI yet. Contact your system administrator if a user should be blocked from specific cameras.

## Active users

The web UI does not show who is currently logged in. You cannot kick sessions from the UI.
